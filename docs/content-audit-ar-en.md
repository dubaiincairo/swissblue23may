# Swiss Blue bilingual content audit

Audit date: 14 July 2026

## Scope

Reviewed the public Arabic root routes and matching English `/en` routes for the homepage, properties, serviced apartments, destinations, about, offers, careers, corporate requests, central reservations, contact, feedback, policy, FAQ, dining, meetings, loyalty, and shared navigation/footer content.

## Corrections implemented

| Area | Arabic and English correction |
| --- | --- |
| Jazan availability | Jazan is presented as coming soon instead of an operating or bookable branch. |
| Booking | Jazan is removed from the property selector. Open properties show both property and city. |
| Property access | The Jazan card is non-clickable and its detail route returns the not-found page until launch. |
| Portfolio totals | Operating totals are aligned to five open properties, two open cities, and 227 open rooms/apartments, with Jazan described separately as upcoming. |
| Central reservations | Copy now limits current booking and multi-property support to Jeddah and Riyadh and identifies Jazan as upcoming. |
| Careers and corporate copy | Current operations are described as Jeddah and Riyadh, with expansion to Jazan stated as future activity. |
| Footer and destination labels | Both languages use an explicit coming-soon label for Jazan. |
| Hospitality gallery | Scene-specific captions are migrated to neutral numbered titles so photos can be replaced without misleading labels. |
| Feedback page | Removed the oversized service-promise/contact-card section requested by the owner while retaining commitments, process, escalation, and contact flow. |
| UI terminology | English `B2B Request Form` capitalization and `Corporate Requests` naming remain standardized. |

## Editorial findings requiring owner evidence

The following content should not be strengthened or treated as verified until the business team provides source records:

- Named guest testimonials, profile images, ratings, and booking-platform attribution.
- Claims such as best-rate guarantees, number of verified travel partners, daily guest capacity, and service response times.
- Exact amenity availability at each operating property.
- Final unit count, opening date, address, and services for the upcoming Jazan property.

These items remain editable in the CMS. The new chatbot knowledge manager can hold approved PDFs and public links so operational answers are based on controlled sources rather than marketing assumptions.

## Language quality notes

- Arabic and English now express the same availability state and booking limitations.
- Arabic labels use direct Modern Standard Arabic and preserve native RTL behavior.
- English copy uses consistent sentence case and avoids presenting Jazan as open.
- Property names remain branded names; availability is communicated in a separate status label to avoid permanently changing the brand name in the CMS.
